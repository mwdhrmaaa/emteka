# Emteka - Your Mathematical Companion

Emteka is a modern, premium web application designed to help students and professionals with their mathematical needs.

## Features

-   **Scientific Calculator**: A fully featured calculator for complex calculations.
-   **Problem Solver**: Intelligent tool to solve standard math problems (Algebra, Equations).
-   **Math Formulas**: Comprehensive library of formulas for Geometry, Algebra, Trigonometry, and more.

## Tech Stack

-   **Framework**: Laravel 11
-   **Styling**: TailwindCSS v4
-   **Scripting**: Vanilla JavaScript (ES6+)

## Installation

1.  Clone the repository:
    ```bash
    git clone https://github.com/mwdhrmaaa/emteka.git
    cd emteka
    ```

2.  Install dependencies:
    ```bash
    composer install
    npm install
    ```

3.  Run the development server:
    ```bash
    npm run dev
    ```

4.  Serve the application:
    ```bash
    php artisan serve
    ```
